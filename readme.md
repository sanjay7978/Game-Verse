# 🎮 GameVerse

> Play. Compete. Dominate.

GameVerse is a modern neon-themed arcade platform built with React and Vite. Players can create profiles, play multiple browser-based mini-games, earn XP, unlock achievements, climb leaderboards, and customize their gaming experience.

---

## ✨ Features

### 🎯 Multiple Mini Games
- Simon Game
- Memory Cards
- Aim Trainer
- Whack-a-Mole
- Tic Tac Toe
- Rock Paper Scissors

### 👤 User Profiles
- Create and manage player profiles
- Avatar selection
- XP and Level progression
- Track game statistics

### 🏆 Leaderboards
- Game-specific rankings
- High score tracking
- Performance comparison

### 🎖️ Achievement System
- Unlock badges by completing challenges
- Track achievement progress
- Showcase accomplishments

### 🎨 Custom Themes
- Neon-themed UI
- Multiple theme options
- Personalized gaming experience

### 🔊 Interactive Experience
- Sound effects
- Smooth animations
- Responsive design
- Beautiful glassmorphism interface

## 🚀 Installation

### Clone the Repository

```bash
git clone https://github.com/yourusername/gameverse.git
```

### Navigate to Project

```bash
cd gameverse
```

### Install Dependencies

```bash
npm install
```

### Start Development Server

```bash
npm run dev
```

### Build for Production

```bash
npm run build
```

### Preview Production Build

```bash
npm run preview
```
